# Muhammed Mubashir — Portfolio Website

A clean, modern, and high-performance portfolio website built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Vite**.

Designed specifically for **Muhammed Mubashir** (Software Developer at Ziqx Creative Clique LLP & BCA in AI, VR & AR with Cloud Computing at Srinivas University).

---

## 🚀 Key Highlights & Features

- **⚡ Modern Tech Aesthetic**: Ultra-clean cyber-dark theme with glassmorphism, responsive navigation, and subtle gradient glows.
- **🏎️ Live Interactive OBD-II Telemetry Simulator**: An interactive automotive diagnostic simulator allowing recruiters to test Cruising, Sport Mode, and Engine Fault diagnostic codes with live simulated CAN-bus hexadecimal telemetry packet streams.
- **💼 Comprehensive Experience & Education Showcase**: Clear timeline featuring role at Ziqx Creative Clique LLP, BCA degree at Srinivas University, and freeCodeCamp developer certifications.
- **📁 Filterable Project Portfolio**: Interactive showcase featuring Unity AR Solar System, OBD System Reader Dashboard, Full-Stack E-Commerce, Smart Attendance Tracker, Expense Tracker, and AI Chatbot with expandable architectural breakdown modals.
- **📄 Printable Resume Modal**: Complete curriculum vitae modal with a 1-click **"Print / Save as PDF"** feature optimized for recruiters.
- **📬 Instant Direct Contact**: Contact form with automatic email drafting and 1-click **WhatsApp instant chat integration** (`+91 96053 42418`).

## 🛠️ Quick Start

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized, minified bundle in the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```

## 🌐 Free 1-Click Deployment Options

### Deploy to Vercel (Recommended)
1. Push this repository to your GitHub account: `https://github.com/Mxxdmubashir/portfolio`
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Framework Preset: **Vite** (auto-detected).
4. Click **Deploy**. Done in 30 seconds!

### Deploy to Netlify
1. Go to [netlify.com](https://netlify.com) and drag & drop the `dist/` folder, or connect your GitHub repository.
2. Build command: `npm run build`
3. Publish directory: `dist`

### Deploy to GitHub Pages
1. In `vite.config.ts`, add `base: '/<repo-name>/'`.
2. Run `npm run build`.
